# Projeto Barbearia ✂️💈

Landing page moderna e responsiva desenvolvida para agendamentos e apresentação de serviços de barbearia.

## 🚀 Tecnologias Utilizadas
- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Estilização moderna, layout responsivo e animações.
- **JavaScript:** Interatividade e lógica de navegação.

## 💻 Sobre o Projeto
O objetivo principal é oferecer uma experiência intuitiva e rápida para o usuário agendar serviços pelo smartphone ou computador, focando na conversão de clientes para negócios locais.
